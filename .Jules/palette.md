## 2026-03-30 - Form Accessibility and Micro-UX Character Feedback
**Learning:** For dynamic ad creative tools, screen reader accessibility requires proper association of form labels with inputs using `id` and `htmlFor`. When implementing character limits, immediate visual cues such as color-coded thresholds (orange at 80%, red over limit) and structured flex layouts (label left, counter right) make fields intuitive and highly usable. Additionally, simulated AI generation needs artificial delay (e.g. 800ms) with a disabled/loading state (spinning icons) to build a premium perception of complexity.
**Action:** Always map inputs to labels via `useId` and `htmlFor`, support interactive hover indicators, and construct custom loading animations for AI triggers using memory-safe `useRef` timer cleanups.
