## 2026-03-05 - Standardized Input Accessibility and Simulating AI Generation in Meta Ads Creator
**Learning:** Associating form input/textarea elements with corresponding labels using React's `useId` and `htmlFor` properties is critical for screen readers and improves click targets. Furthermore, when simulating AI generation, introducing an artificial delay of ~800ms paired with an animated `RefreshCw` loading icon and a disabled state prevents double submissions and greatly enhances the user's perception of complexity and value.
**Action:** Always generate unique element IDs using `useId` in reusable components to link labels and inputs securely, and implement robust async-simulating timers on any "Magic Generate" or AI button actions with appropriate cleanup on unmount.
