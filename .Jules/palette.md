## 2025-05-15 - [Accessible Form Fields & AI Delight Pattern]
**Learning:** Using `useId` for form field association is essential for accessibility. Pairing AI generation with a simulated delay and loading state (the "Delight" pattern) improves perceived value and provides clear feedback.
**Action:** Always associate labels with inputs using `useId` and `htmlFor`. Add `cursor-pointer` to labels for better visual feedback. Implement artificial delays (e.g., 800ms) with loading indicators for AI-powered features.
