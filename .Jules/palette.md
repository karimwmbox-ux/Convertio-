## 2025-05-14 - [AdCreator Accessibility and Feedback]
**Learning:** Using `useId` for form fields ensures stable and unique IDs for `htmlFor` association, improving accessibility. Adding a simulated delay for AI features with a clear loading state (`RefreshCw` spinner and "Generating..." text) significantly improves perceived quality and prevents double submissions.
**Action:** Always associate labels with inputs using `useId` and include artificial delays for simulated AI features to match user expectations of "complexity".
