## 2025-05-14 - AI Generation Delight Pattern
**Learning:** Adding an artificial delay (800-1200ms) with a loading state (e.g., "Generating...") to instant AI actions improves user perception of value and complexity.
**Action:** Use `setTimeout` and `isGenerating` state for simulated AI tasks.

## 2025-05-14 - Accessibility for Dynamic Forms
**Learning:** Association of labels and inputs using `useId` is critical in reusable React components to avoid ID collisions while ensuring screen reader compatibility.
**Action:** Always use `useId` for `htmlFor` and `id` attributes in form fields.

## 2025-05-14 - Interactive Label Feedback
**Learning:** Users expect visual feedback when hovering over labels associated with inputs.
**Action:** Apply `cursor-pointer` to `<label>` elements when linked to an input.
