# Palette Journal

## 2026-03-05 - Ad Field Accessibility & Character Counts
**Learning:** For Meta Ads managers, ad creation screens benefit immensely from direct character guidance matching actual platform recommendations (e.g. 40 characters for Headlines, 125 characters for Primary Text/Body), paired with responsive, highly visual warning thresholds (orange at 80% and red when exceeded) and keyboard accessibility associations (proper input labels with cursor-pointer indicator).
**Action:** Always implement robust labels, useId-based IDs matching standardized accessibility IDs (e.g. nameId, bodyId, headlineId, ctaId, imageUrlId), dynamic counters with color states, and test with accessibility guidelines.
