## 2025-05-15 - Form Accessibility & Feedback Patterns
**Learning:** In highly interactive ad-creation tools, users benefit significantly from real-time character limit feedback and accessible form associations. Using `useId` for stable label-input linking and `cn` for threshold-based color coding (orange at 80%, red at 100%) provides clear, non-intrusive guidance.
**Action:** Always implement `useId` for form components and include character counters with color-coded thresholds for text fields with strict constraints.
